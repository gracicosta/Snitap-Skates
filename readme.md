# 🛼 Snitap — Landing Page

Landing page inspirada no universo dos patins, desenvolvida com **HTML5 e CSS3**, com foco na prática de animações, transições e efeitos visuais.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- CSS Animations e Keyframes
- Flexbox e CSS Grid

## ✨ Funcionalidades

- Animações de entrada dos elementos
- Textos animados com transições entre palavras
- Banner com movimento contínuo
- Galeria de fotos com efeitos de hover e zoom
- Animações ativadas durante a rolagem da página
- Efeitos interativos em botões e ícones

## 🎯 Objetivo

Projeto desenvolvido para aprimorar minhas habilidades em desenvolvimento front-end, explorando diferentes recursos de animação do CSS e a construção de interfaces modernas e interativas.

1. Clone o repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/snitap.git
   ```
2. Abra a pasta do projeto no VS Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
